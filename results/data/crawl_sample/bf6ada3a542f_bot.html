Wordworth 7 on AmigaOS4.1
ChrisH   Other   2011/6/17 10:16
4163 0   
This shows Wordworth 7 running on AmigaOS4.1 (Update 2).

To get it to work on AmigaOS4, you need to add the PICASSO=TRUE tooltype, and some settings in Sys:Prefs/Screens. Those settings are described here.
