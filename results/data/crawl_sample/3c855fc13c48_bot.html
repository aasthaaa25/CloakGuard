    Takbo ng Pamilyang Manileno 2014 will be on April 6, 2014 at Quirino Grandstand, Roxas Boulevard, Manila. This is a fund raising project for the Kaagapay ng Manileno Foundation programs. This is event is in cooperation with Vice Mayor Isko Moreno and organized by Kaagapay ng Manileno Foundation.

    Takbo ng Pamilyang Manileno 2014
    April 6, 2014 @ 4:30AM
    Quirino Grandstand Roxas Boulevard, Manila
    3K / 5K / 10K
    Organizer: Kaagapay ng Manileno Foundation

    Registration Fees:
    3K- Php 300
    5K – Php 400
    10K – Php 500

    Sponsored
