## What was repaired in code

- Jargon mass is the raw keyword-hit count. The previous mass was the sum of an L1-normalized vector, so it could only be 0 or 1.
- Jensen–Shannon is the divergence in bits, log base 2, with both-empty defined as 0 and one-empty defined as 1. It is not the square-root distance.
- Fusion returns `scoring_path` and `score_is_probability: false`. The operational score is a fixed-weight heuristic, or the URL-model-assisted heuristic when `model.joblib` loads. The trained multimodal ensemble is a different, archived path.
- New dataset builds keep missing paired-view features as NaN and do not treat the fusion threshold as `label`.
- Owner-authorized mode may rate-limit, block, or serve an inert decoy. `DEFENSE_MODE=external_monitor` only forwards and logs.
- JA3 points attach to the observed client hash, not to a remote operator.
- Forensic packages say `HEURISTIC ALERT` rather than `CLOAKING CONFIRMED`.
